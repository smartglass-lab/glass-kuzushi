# グラスブロックくずし — Glass Kuzushi

Meta Ray-Ban Display 用の**ブロックくずし**。←→でパドルを動かし、タップでボールを発射。パドルの端で打つほど鋭い角度に飛ぶ。落ちてくるカプセルを取ると **W ワイド／M マルチボール／S スロー／♥ ライフ** のパワーアップ。5ステージ（銀の2回ブロック入り）をひとまわりすると、さらに速くなってループ。ハイスコアを保存。依存ライブラリなし・オフライン動作。

- **ライブURL**: https://glass-kuzushi.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / Canvas / 静的サイト）

## 特徴

- **タップとD-padだけで遊べる** — ←→＝パドル移動（1回のスライドで44px、押しっぱなしで連続）、タップ＝発射。戻るジェスチャーは使わず、どの画面もタップで先へ進める
- **角度はパドルの当て方で決まる** — まん中はまっすぐ上、端に近いほど最大65°の鋭角。狙って打ち分けられる
- **4種のパワーアップ** — ブロックをこわすと20%でカプセルが落ちる。W＝パドルが1.5倍幅（12秒）、M＝すべてのボールが3つに分裂（最大9個）、S＝ボールが0.65倍速（8秒）、♥＝ライフ+1（最大5）
- **5つのステージ** — 横一列／市松／ひし形／銀ブロックの二重枠／ハート。銀ブロックは2回当てるとこわれて高得点。5ステージごとにループして基本速度アップ
- **すり抜けなしの当たり判定** — ボールの移動をサブステップに分割し、速くなってもブロックやパドルを貫通しない
- **加算式ディスプレイ向けの絵** — 純黒の背景は透明。ブロックは行ごとのネオンカラーで発光、ボールは白、パドルは金色（ワイド中は水色）。こわれたブロックは色の破片がはじける
- **タイトルで開始ステージを選べる** — 「ステージ ◀ n ▶」を←→で変更。ハイスコアは localStorage に保存

## 操作方法

| 画面 | 操作 |
|------|------|
| タイトル | ↑↓でえらび、タップで「▶ はじめる」／「ステージ」（←→で1〜5）／「❓ あそびかた」 |
| プレイ | ←→＝パドルを動かす、タップ＝ボールを発射（ミス後も同様） |
| ステージクリア | タップで つぎのステージへ |
| ゲームオーバー | ↑↓でえらび、タップで「🔄 もういちど」／「◀ タイトルへ」 |
| あそびかた | タップで とじる |
| PC確認用 | Escape でタイトルへ戻る、クリックで発射／パドル移動／ボタン操作（グラスの戻るジェスチャーは使用不可のため補助のみ） |

`?demo=1` を付けると乱数が固定され、パドルがボールを自動で追いかけます（デモ録画用。記録は保存されません）。

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E3%83%96%E3%83%AD%E3%83%83%E3%82%AF%E3%81%8F%E3%81%9A%E3%81%97&appUrl=https%3A%2F%2Fglass-kuzushi.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラスブロックくずし`、URL `https://glass-kuzushi.vercel.app` を入力。
